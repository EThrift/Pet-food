In all csvs Presence of plastic, polymer, or shape 1=present, 0=absent
Each sample of each brand was given a code as seen in the plastic presence csv 
Microplastic_petfood_overall_presence_Rscript.R is the code used to run analyses and make plots on the overall presence of plastics in the samples and products
Microplastic_petfood_Overall_plastic_presence All.csv shows for the 63 combinations of target animal, food type and price band, the presence/absence of microplastics in the samples tested.
Microplastic_petfood_Overall_plastic_presence plot target animal sample.csv shows the number of samples for each target animal, which contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 1. 
Microplastic_petfood_Overall_plastic_presence plot target animal product.csv shows the number of products for each target animal, which contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 1. 
Microplastic_petfood_Overall_plastic_presence plot food type sample.csv shows the number of samples for each food type, which contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 1. 
Microplastic_petfood_Overall_plastic_presence plot food type product.csv shows the number of products for each food type, which contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 1. 
Microplastic_petfood_Overall_plastic_presence_plot price sample.csv shows the number of samples for each price category, which contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 1. 
Microplastic_petfood_Overall_plastic_presence plot price product.csv shows the number of products for each price category, which contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 1. 
Microplastic_petfood_shape_Rscript.R is the code used to run analyses and make plots on the shape (fragments and fibres) in the samples tested.
Microplastic_petfood_shape_fibre.csv shows for the 63 combinations of target animal, food type and price band, the presence/absence of fibres in the samples tested.
Microplastic_petfood_shape_fragment.csv shows for the 63 combinations of target animal, food type and price band, the presence/absence of fragments in the samples tested.
Microplastic_petfood_size.csv shows the size of the 95 microplastics with the associated combinations of target animal, food type and price band. 
Microplastic_petfood_size_Rscript.R is the code used to run analyses and make plots on the size of the microplastics in the samples tested.
Microplastic_petfood_Target animal shape plot.csv shows the number of fragments and fibres for each target animal that contained microplastics (n), the total number of samples tested for each (total), and the percentage. This was used to create Figure 2. 
Microplastic_petfood_Food type shape plot.csv shows the number of fragments and fibres for each food type that contained microplastics (n), the total number of samples tested for each (total), and the percentage. This was used to create Figure 2. 
Microplastic_petfood_Price shape plot.csv shows the number of fragments and fibres for each price category, that contained microplastics (n), the total number of samples tested for each (total) and the percentage. This was used to create Figure 2. 
Microplastic_petfood_polymer_Rscript.R is the code used to run analyses and make plots on the different polymer types and uses in the samples and products
Microplastic_petfood_Polymer all.csv shows for the 63 combinations of target animal, food type and price band, the presence/absence of different potential polymers in the samples tested. 
Microplastic_petfood_Polymer use long.csv shows for the 64 combinations of target animal, food type and price band, the use of the polymers in each sample. Where there was more than one polymer with a different use per sample, extra lines were added to account for this. 
Microplastic_petfood_Polymer combined.csv shows the number of each polymer type (n) within each product across the six samples tested and gives a total count (total) and percentage. This resulted in 59 lines in this dataset.   
Microplastic_petfood_plastic_per_gram_Rscript.R is the code used to run analyses and make plots on the number of microplastic per gram in the samples tested.
Microplastic_petfood_plastic_oer_gram.csv shows for the 63 combinations of target animal, food type and price band, the number of microplastics per gram in the samples tested.
